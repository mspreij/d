# what in the fuck *is* LUKS?
\e[32;1mLinux Unified Key Setup\e[0m is a disk encryption specification: https://en.wikipedia.org/wiki/Linux_Unified_Key_Setup

# list LUKS things
# blkid: block ID / block device identification
# run it on its own to see all the devices with UUIDs, and with the following arguments to see only the encrypted ones
$ blkid -t TYPE=crypto_LUKS -o device
# with more context:
$ lsblk -f

# check the passphrase of a specific partition
cryptsetup luksOpen --test-passphrase   /dev/vdb

# to be sure - if you don't know what /dev/vdb should be in your case,
$ blkid -t TYPE=crypto_LUKS -o device \e[36m# returns candidates\e[0m

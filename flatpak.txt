Flatpak = application packaging/sandboxing system for Linux.
Apps are installed separately from the distro's normal apt/dnf packages.
They use shared runtimes, so apps can carry newer dependencies than the host OS.
Useful when a distro package is outdated or broken, but uses more disk space.

flatpak remotes
    List configured repositories/remotes.

flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
    Add Flathub, the main public Flatpak repository.

flatpak search <some-app>
    Search available applications.

# Apostrophe is an example application here
flatpak install flathub org.gnome.gitlab.somas.Apostrophe
    Install an application from Flathub.

flatpak list
    List installed Flatpak apps and runtimes.

flatpak run org.gnome.gitlab.somas.Apostrophe
    Start an application manually.

flatpak update
    Update all installed apps and runtimes.

flatpak uninstall org.gnome.gitlab.somas.Apostrophe
    Remove an application.

flatpak uninstall --unused
    Remove runtimes/dependencies no longer needed.

flatpak info org.gnome.gitlab.somas.Apostrophe
    Show version, runtime, permissions and installation details.

flatpak history
    Show recent Flatpak installs/updates/removals.

flatpak override --show org.gnome.gitlab.somas.Apostrophe
    Show manually configured permission overrides.
